# Pi Command Center

A responsive Raspberry Pi project guide deployed on Vercel.

## Production architecture

- Shared Raspberry Pi Setup V2: six self-hosted 1122×1402 SVG tutorials with a strict manifest.
- Smart Mirror V17.2: deterministic 16-step visual course.
- Responsive V1: phone, tablet, desktop, landscape, touch, safe-area and Pi-display support.
- Service worker V55: caches the shell and all Shared Setup V2 visuals.
- Build validation blocks legacy setup JPG references, old Smart Mirror enhancement scripts, missing setup visuals, and stale cache configuration.
