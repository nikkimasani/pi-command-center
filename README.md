# Pi Command Center

A responsive Raspberry Pi project guide deployed on Vercel.

## Production architecture

- Shared Raspberry Pi Setup V2: six self-hosted 1122×1402 SVG tutorials with a strict manifest and matching fallback dataset.
- Smart Mirror V17.2: deterministic 16-step visual course with project-specific hardware and software references.
- Project Courses V1.1: project-specific responsive vector visuals for every remaining project, reliable visual refresh on every step change, plus Progress and Project Files surfaces.
- Responsive V1: phone, tablet, desktop, landscape, touch, safe-area and Pi-display support.
- Raspberry branding: custom raspberry artwork replaces the incorrect strawberry placeholder in the app shell and PWA icons.
- Service worker V56: caches the production shell, completion layers and all Shared Setup V2 visuals.
- Build validation blocks legacy setup assets, old Smart Mirror enhancement scripts, missing setup visuals, missing completion features, stale cache configuration and reintroduction of generic project placeholders.
