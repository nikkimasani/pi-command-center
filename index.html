Raspberry Pi 5 orientation

  • USB-C is power. Connect it last after assembly.
  • microSD is on the underside of the board.
  • The 40-pin header carries 3.3 V GPIO plus 3.3 V, 5 V, and ground pins.
  • MIPI connectors are used for supported display/camera ribbons. Never force a ribbon.

Raspberry Pi Imager and first boot

  1. Install Raspberry Pi Imager on your Mac, Windows, or Linux computer.
  2. Choose Raspberry Pi 5.
  3. Choose the current Raspberry Pi OS 64-bit Desktop image.
  4. Select the correct microSD card.
  5. Preconfigure username, Wi-Fi, hostname, locale, and SSH.
  6. Write, verify, eject, then insert the card while the Pi is powered off.
  7. Connect display and keyboard first. Connect USB-C power last.
  8. After first boot, run sudo apt update and sudo apt full-upgrade -y.

DSI / MIPI ribbon safety

  • Shut down and disconnect USB-C before opening a ribbon latch.
  • Open both sides of the latch evenly.
  • Match the gold-contact orientation to the exact board and display connector.
  • Insert straight and fully. Close the latch evenly.
  • Use a gentle bend radius. Never crease the ribbon sharply.
